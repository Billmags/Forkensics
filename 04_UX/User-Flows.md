# Core User Flows — Draft

## Create a challenge

Open group → create challenge → capture/select photo → enter and confirm dish → choose venue/location → add optional note → choose reveal rule → preview privacy-safe challenge → post.

## Make a guess

Receive notification → open challenge → inspect photo → enter dish guess → enter restaurant/city or drop map pin → optionally request a hint → review → submit or lock.

## Reveal

Deadline/all-guessed/manual-close condition occurs → official dish and location appear → points and explanation appear → player standings update → reactions and comments open.

## Join a group

Open invite → sign in/create profile → review group identity and privacy → join → see open rounds.

## Delete or correct

Poster may correct the official answer before reveal with an audit note. Deleting an open challenge cancels it and does not alter standings. Account and content deletion behavior requires approval.

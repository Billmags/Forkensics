# PB-UI-001 — Forkensics Design System
## PART 1 — Design Principles
**Status:** Draft v1

---

## PURPOSE

The Forkensics interface should disappear.

Players should think about the food.
Not the software.

Every decision made throughout the application should support that philosophy.

If a design decision makes the interface more noticeable than the mystery itself, it is probably the wrong decision.

---

## DESIGN PHILOSOPHY

Forkensics is not a productivity app.
It is not social media.
It is not a restaurant finder.
It is a premium game built around curiosity.

The interface exists only to move players from one mystery to the next with as little friction as possible.

The food is the hero.
The mystery is the experience.
The interface is invisible.

---

## THE TEN PRINCIPLES

**1. FOOD IS THE HERO**
Every screen should immediately communicate food. Photography should dominate. UI should support. Never compete.

**2. ONE PRIMARY ACTION**
Every screen has one obvious next step. Guess. Post. Reveal. Comment. Never present multiple competing calls to action.

**3. REMOVE EVERYTHING THAT DOESN'T HELP PLAY**
Every element must justify its existence. If removing something makes the screen easier to understand, remove it.

**4. CLARITY OVER CLEVERNESS**
The game itself provides enough mystery. The interface should never be mysterious. Buttons. Labels. Inputs. Navigation. Everything should be obvious.

**5. PROGRESS SHOULD ALWAYS BE VISIBLE**
Players should never wonder: "What happens next?" Timers. Guess status. Challenge status. Leaderboard position. Everything important should always be visible.

**6. THE GAME SHOULD FEEL FAST**
Animations should be quick. Interactions should feel immediate. The app should encourage "Just one more mystery."

**7. EVERY SCREEN SHOULD FEEL PREMIUM**
Large photography. Large typography. Generous spacing. Minimal color. Confidence. Never clutter.

**8. REWARD CURIOSITY**
Players should constantly feel like they are getting closer. Reveal information gradually. Celebrate discoveries. Make every reveal satisfying.

**9. CONSISTENCY BUILDS TRUST**
Buttons behave consistently. Cards behave consistently. Navigation behaves consistently. Typography behaves consistently. Players should never relearn the interface.

**10. DESIGN FOR APPLE FEATURE QUALITY**
Every screen should be capable of appearing inside an Apple editorial feature. Ask one question before approving any design: "Would Apple proudly feature this screen?" If the answer is no, continue refining.

---

## THE GOLDEN RULE

If forced to choose between adding another feature or making the existing experience more beautiful, always choose beauty.

Beautiful software feels easier to use.

---

## THE NORTH STAR

The player should forget they are using an app.
They should feel like they are solving delicious mysteries.

# Roles and Responsibilities

## Bill — Product owner

- Defines the desired experience and priorities.
- Resolves product disagreements.
- Gives final approval for every step.
- Owns accounts, budgets, legal decisions, and release authorization.

## Claude — Sole application-code author

- Evaluates technical feasibility.
- Writes Swift, backend, database migrations, tests, and build configuration.
- Keeps implementation within approved scope.
- Supplies implementation and test evidence.
- Corrects issues found during review.

## Codex/GPT — Planner and independent reviewer

- Structures requirements, user flows, scope, roadmap, and acceptance criteria.
- Reviews architecture, conceptual schema, AI behavior, privacy, and security.
- Challenges assumptions and identifies missing cases.
- Reviews Claude's implementation, diffs, and test evidence.
- Does not write application code.

## Shared responsibility

All three reviewers must work from the same versioned review packet before a coding step begins.

# Review Packets

Each proposed coding step receives one numbered document containing:

- Objective
- User value
- Included scope
- Excluded scope
- User flow and screens
- Data and API changes
- Privacy and security impact
- Error and edge-case behavior
- Acceptance criteria
- Test plan
- Risks and open questions
- Claude review notes
- Codex review notes
- Bill's final decision

Use names such as `Step-01-App-Shell.md`. No packet is approved until Bill records the explicit approval in the document and Decision Log.

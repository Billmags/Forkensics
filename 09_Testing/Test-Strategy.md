# Test Strategy — Draft

Every approved coding step must include acceptance tests proportional to its risk.

## Core categories

- Challenge lifecycle and state transitions
- Group membership and authorization
- Hidden-answer confidentiality before reveal
- Food-answer comparison and scoring boundaries
- Geographic distance and partial-credit calculations
- Deadline, time-zone, retry, and duplicate-submission behavior
- Photo sanitization and metadata removal
- Account/content deletion
- Offline and poor-network behavior
- Push-notification routing and privacy
- Accessibility: VoiceOver, Dynamic Type, contrast, motion, and touch targets
- Device and supported-iOS compatibility

## Completion evidence expected from Claude

- Changed-file summary
- Automated tests run and results
- Manual scenarios tested
- Screenshots or recordings when visual behavior matters
- Known limitations
- Confirmation that no unapproved scope was added
